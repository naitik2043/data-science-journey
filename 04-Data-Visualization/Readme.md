# 📊 Data Visualization

This folder contains my Data Visualization practice notebooks as part of my **Data Science Journey**. It focuses on transforming raw data into meaningful visual insights using **Matplotlib** and **Seaborn**. The notebooks cover a wide range of visualization techniques that are essential for Exploratory Data Analysis (EDA), data storytelling, and Machine Learning workflows.

- Introduction to Matplotlib
- Bar Plots

- Histograms
- Scatter Plots
- Subplots
- Introduction to Seaborn
- Statistical Visualizations with Seaborn
