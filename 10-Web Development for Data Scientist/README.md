# 🌐 Web Development for Data Scientists

This folder contains my **Web Development for Data Scientists** practice as part of my **Data Science Journey**. It focuses on building web applications using **Flask** and introduces the essential concepts required to integrate Machine Learning models with web interfaces.

The projects cover Flask fundamentals, form handling, Jinja templating, and template inheritance, providing a strong foundation for deploying Data Science and Machine Learning applications.

---

## 📚 Topics Covered

- Introduction to Flask
- Static Files & Static Folder Management
- Handling Forms in Flask
- Jinja Templating
- Template Inheritance
- Building Dynamic Web Applications

---

## 📂 Contents

| No. | Project | Description |
|:---:|---------|-------------|
| 01 | Changing Static Paths & Static Folders | Learn how Flask manages static files such as CSS, JavaScript, and images. |
| 02 | Handling Forms in Flask | Create and process HTML forms using Flask. |
| 03 | Jinja Templates in Flask | Build dynamic web pages using the Jinja templating engine. |
| 04 | Template Inheritance in Flask | Reuse layouts efficiently using template inheritance. |
