## 📖 About

This repository documents my structured learning journey in **Data Science, Machine Learning, Deep Learning, and Artificial Intelligence**.

It contains well-organized Jupyter notebooks, practical implementations, mini projects, datasets, presentations, and learning notes covering the complete Data Science workflow—from Python programming and data analysis to Deep Learning and Web Development for Data Scientists.

Beyond the practical implementations available in this repository, I also explored **Large Language Models (LLMs), AI-assisted development workflows, Git for Data Scientists, and Google Colab** as part of my learning journey.

The objective of this repository is to build a strong foundation in Data Science while maintaining a clean, well-documented portfolio of my learning and practical work.
