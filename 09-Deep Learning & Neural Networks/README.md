# 🧠 Deep Learning & Neural Networks

This folder contains my **Deep Learning & Neural Networks** practice as part of my **Data Science Journey**. It introduces the fundamental concepts of Deep Learning and demonstrates how neural networks learn from data to solve complex prediction and classification problems.

The notebooks cover the basics of perceptrons, neural network training, visualization of the MNIST dataset, and building a neural network for handwritten digit classification.

---

## 📚 Topics Covered

- Introduction to Deep Learning
- Perceptron
- Training a Perceptron
- Neural Networks
- MNIST Dataset
- Data Visualization
- Handwritten Digit Classification
