# 🏠 House Price Prediction

This project is part of my **Data Science Journey** and demonstrates an end-to-end Machine Learning workflow for predicting house prices using the **California Housing Dataset** and the **Scikit-Learn** library.

The project covers every major step involved in building a Machine Learning model, from data exploration and preprocessing to feature engineering, pipeline creation, model training, and final prediction.

---

## 📚 Topics Covered

- Data Exploration
- Data Visualization
- Creating Training & Test Sets
- Handling Missing Values
- Handling Categorical Attributes
- Feature Scaling
- Scikit-Learn Pipelines
- Model Training
- House Price Prediction

---

## 📂 Contents

| No. | Notebook | Description |
|:---:|----------|-------------|
| 01 | Analyzing the Data | Explore and understand the housing dataset. |
| 02 | Creating a Test Set | Split the dataset into training and testing sets. |
| 03 | Creating Training & Test Sets | Prepare the dataset for model development. |
| 04 | Visualizing the Data | Visualize important patterns and relationships. |
| 05 | Handling Missing Data | Deal with missing values using preprocessing techniques. |
| 06 | Handling Categorical Attributes | Encode categorical features for Machine Learning. |
| 07 | Feature Scaling | Normalize and standardize numerical features. |
| 08 | Scikit-Learn Pipelines | Build preprocessing pipelines for efficient workflows. |
| 09 | Final Model | Train, evaluate, and use the final House Price Prediction model. |
